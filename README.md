# Shane Turner

Web developer and data visualisation specialist based in New Zealand.

I make complex information legible — data, content, and systems that matter to people, built into web applications they can actually use. My work spans interactive data visualisations and infographics, structured content architecture, and tools built around data that existed but wasn't usable until someone built the right interface around it.

I work best with independent professionals, schools, civic organisations, and specialist trades — clients where the brief has a real purpose and there is room to make good decisions.
